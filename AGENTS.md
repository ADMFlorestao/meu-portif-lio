# Orientações para este repositório

1. Consulte `_BRAIN/README.md` para localizar a documentação relevante e leia somente os documentos necessários à tarefa. Não leia todo o `_BRAIN` por padrão.
2. Em caso de dúvida sobre uma funcionalidade, consulte o código. O código é a fonte de verdade para o comportamento implementado; distinga-o de diretrizes e planos.
3. Atualize a memória apenas após mudanças relevantes que afetem seu conteúdo. Não atualize todos os documentos por pequenos ajustes nem registre mudanças rotineiras já descritas no Git.
4. Não crie novos documentos sem necessidade comprovada. Prefira links para fontes existentes e evite conteúdo duplicado.
5. Preserve a identidade profissional e a direção visual aprovadas em `_BRAIN/DESIGN_SYSTEM.md` e `_BRAIN/DECISIONS.md`.
6. Antes de usar capturas, consulte `portfolio-assets/README.md` e faça revisão visual. Não presuma aprovação para publicação.
